# Caesar — website rebuild

A rebuild of [caesar.co.il](https://www.caesar.co.il/) for **קיסר ניהול נכסים**
(Caesar Property Management) as a scroll-driven marketing site. Hebrew, full RTL.

Next.js (App Router) · TypeScript · Tailwind · GSAP ScrollTrigger · Lenis · Macaly Cloud.

## Layout

| Path | What |
| --- | --- |
| `PLAN.md` | Phase checklist and current status |
| `contracts/` | Binding contracts shared by both agents — content schema, motion presets, asset rules |
| `content/` | Harvested source content, brand research, `pages.json` |
| `.claude/agents/` | The two subagent definitions |
| `archive/source/` | Original scrape data, kept as content provenance |

Work is in progress; see `PLAN.md` for what is done and what is blocked.
